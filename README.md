# سرزمین مادری — Sarzamin-e Madari (Motherland)

بازی دفاع از جزیره به سبک **Bad North: Jotunn Edition** با موضوع **ایران هخامنشی در برابر مهاجمان یونانی**.
موتور: **Godot 4.5+** — زبان اصلی: **GDScript** (C# فقط در صورت نیاز به مسیرهای سنگین).

A Bad North–style island defense prototype set in Achaemenid Persia vs Greek invaders.
Engine: Godot 4.5+ — Primary language: GDScript.

---

## ▶️ اجرا / How to run

1. **Godot 4.5 یا جدیدتر** را از [godotengine.org](https://godotengine.org/download) نصب کنید (نسخه‌ی استاندارد، بدون .NET هم کافی است).
2. Godot → **Import** → فایل `project.godot` این پوشه را انتخاب کنید.
3. پس از باز شدن، صبر کنید ایمپورت تمام شود، سپس **F5** (اجرای صحنه‌ی اصلی = منو).
4. در منو، دکمه‌ی «آزمون مسیریابی — ۱۰ سرباز» را بزنید.

> اولین باز شدن پروژه در ادیتور، فایل‌های ایمپورت (فونت/ترجمه) را می‌سازد؛ چند ثانیه طول می‌کشد.

## 🎮 کنترل‌های صحنه‌ی آزمون / Test scene controls

| کلید | عمل |
|---|---|
| **کلیک راست** | جابه‌جایی پرچم هدف (محاسبه‌ی مسیر جدید روی نخ کارگر) |
| **Space** | حرکت آهسته (time_scale = 0.5) |
| **Esc** | بستن/لغو |

## 📊 چه چیزی را باید ببینید؟

- **۱۰ واحد** رنگی از سمت چپ به سمت پرچم طلایی حرکت می‌کنند؛ دور موانع می‌پیچند و برخورد نمی‌کنند.
- واحدی که برسد **نارنجی** می‌شود.
- پنل پایین-چپ (فقط ابزار توسعه — در بازی نهایی طبق قانون آهنین «صفحه‌ی نبرد بدون عدد» حذف می‌شود):
  - `worker compute` = زمان محاسبه‌ی میدان جریان در نخ پایدار (انتظار: زیر ۲ میلی‌ثانیه برای ۳۲×۳۲)
  - `main-thread read` = هزینه‌ی خواندن جهت در نخ اصلی (انتظار: زیر **0.5 میلی‌ثانیه** — معمولاً ~0.001)
  - FPS باید ۶۰ پایدار بماند.

## 📜 قوانین آهنین / Iron laws

1. در صفحه‌ی نبرد: **صفر عدد، صفر نوار سلامت** — همه‌چیز با حالت‌های دیداری (دود، آتش، خون).
2. **نیزه‌دار هنگام حرکت نمی‌جنگد** — فقط در حالت ایست/آماده.
3. مرگ واحد و فرمانده **دائمی** است؛ هیچ بازگشتی وجود ندارد.
4. ذخیره‌ی آهن‌مرد: بدون Reload در میانه‌ی نبرد.
5. FlowField همیشه روی **نخ پایدار** (بدون ThreadPool) با تیک 0.2 ثانیه.
6. WFC حل تعارض را با **seed جدید** انجام می‌دهد، هرگز backtracking.
7. Berserker دشمن خانه غارت نمی‌کند؛ فقط به سربازان حمله می‌کند.
8. لکه‌ی خون روی زمین می‌ماند (قابل خاموش کردن در تنظیمات).
9. UI نبرد: بدون عدد و نوار — فقط آیکون‌ها و پرچم‌ها.
10. دو زبانه: فارسی (RTL) + انگلیسی، از اول.
